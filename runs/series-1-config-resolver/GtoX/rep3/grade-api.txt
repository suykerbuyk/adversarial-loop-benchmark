package config // import "config"


VARIABLES

var ErrInvalidLogLevel = errors.New("config: invalid log level")
    ErrInvalidLogLevel is returned when the effective LogLevel is not one of the
    legal values: "debug", "info", "warn", "error", or "".


TYPES

type Config struct {
	Verbose    bool
	MaxRetries int
	LogLevel   string
	TimeoutSec int
}
    Config is the effective configuration after layer resolution.

func Resolve(defaults, file, env, flags map[string]any) (Config, error)
    Resolve combines four ordered layers into an effective Config. Precedence
    is argument order, low to high: defaults, file, env, flags. The slice of
    maps inside Resolve is the extension point for more layers if the public
    signature is later allowed to change.

    A nil map is an empty layer: every field is absent. A key present in a map
    sets that field, including zero values (false, 0, ""). A key absent from a
    map leaves the field unchanged. If no layer presents a field, the effective
    value is that field's Go zero value.

    A present value of the wrong Go type for its key panics. An unknown key
    panics. Both are programmer errors. Resolve does not read the environment,
    any file, or the command line.

    Validation runs only on the effective LogLevel, after every layer has
    been applied. A presented LogLevel overridden by a higher layer is never
    validated. Verbose, MaxRetries, and TimeoutSec are not validated.
