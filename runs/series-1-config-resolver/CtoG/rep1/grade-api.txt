package config // import "config"

Package config computes an effective configuration from ordered layers.

Layers are supplied as map[string]any values, from lowest to highest precedence:
defaults, file, env, flags. A key present in a layer's map sets the
corresponding field, even when the value is a zero value (false, 0, ""). A key
absent from a layer leaves the value from lower layers in place. A field that no
layer presents keeps its Go zero value.

Supplying an unknown key, or a value whose Go type does not exactly match the
field's type, is a programmer error and causes Resolve to panic.

VARIABLES

var ErrInvalidLogLevel = errors.New("config: invalid log level")
    ErrInvalidLogLevel is wrapped by the error Resolve returns when the
    effective LogLevel is not one of "debug", "info", "warn", "error", or "".


TYPES

type Config struct {
	Verbose    bool
	MaxRetries int
	LogLevel   string
	TimeoutSec int
}
    Config is the effective, resolved configuration.

func Resolve(defaults, file, env, flags map[string]any) (Config, error)
    Resolve merges the four layers, given in increasing precedence order,
    and returns the effective Config. Only the effective LogLevel is validated;
    on an invalid level it returns the zero Config and an error wrapping
    ErrInvalidLogLevel. Resolve never modifies its arguments.

    Resolve panics if any layer contains an unknown key or a value of the wrong
    Go type, even when that value would be overridden by a higher layer.
