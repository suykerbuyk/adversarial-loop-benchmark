package config // import "config"

Package config computes an effective configuration by combining ordered
in-memory layers. A higher-precedence layer overrides a lower one, field by
field. The package performs no I/O: callers supply every layer's values.

VARIABLES

var ErrInvalidLogLevel = errors.New("config: invalid log level")
    ErrInvalidLogLevel is matched (via errors.Is) by the error Resolve returns
    when the effective LogLevel is not one of "debug", "info", "warn", "error",
    or "".


TYPES

type Config struct {
	Verbose    bool
	MaxRetries int
	LogLevel   string
	TimeoutSec int
}
    Config is the effective configuration produced by Resolve.

func Resolve(defaults, file, env, flags map[string]any) (Config, error)
    Resolve combines the layers in increasing precedence: defaults < file < env
    < flags.

    A key present in a layer sets that field, even when the value is a zero
    value (false, 0, ""). A key absent from a layer (or a nil layer) leaves the
    lower value in place. A field that no layer presents gets its Go zero value.

    Only the effective LogLevel is validated. If it is not "debug", "info",
    "warn", "error", or "", Resolve returns the zero Config and an error
    matching ErrInvalidLogLevel.

    Resolve panics on programmer errors, in any layer, even one that a higher
    layer overrides:
      - a value whose dynamic type is not exactly the field's type (bool for
        Verbose, int for MaxRetries and TimeoutSec, string for LogLevel),
        including a nil value;
      - a key other than "Verbose", "MaxRetries", "LogLevel", "TimeoutSec".
        Unknown keys are never ignored and never reported as errors, so a typo
        cannot silently drop a setting.

    Resolve never modifies its arguments and is safe for concurrent use.
