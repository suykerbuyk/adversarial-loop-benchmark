major: `resolveField` validates only the highest-precedence present value, so a wrong-typed value in a lower layer is silently ignored when a higher layer overrides that key. The spec says a present value of the wrong Go type is a programmer error and must panic; for example, `defaults` containing `{"Verbose": "wrong"}` with `flags` containing `{"Verbose": false}` returns normally. Validate every presented legal field in every layer before resolving precedence.
