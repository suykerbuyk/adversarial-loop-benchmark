major: Close treats a process-wide profiler-label pointer as proof that this goroutine may skip the join. reenterMark is one package-level variable, and reenterMarked is true for every goroutine that inherited or was given that pointer, including a Loader of a different Cache. Spec rule 8 says Close waits for every in-flight Loader of the cache being closed. A Loader of cache A that calls B.Close while A's flight mark is set returns from closeFromCallback without loads.Wait. A probe blocked B's Loader, called B.Close from A's Loader, and B.Close returned in microseconds while B's Loader was still blocked; the same skip reproduced under -race. The mark is also cleared by ordinary pprof use on the flight goroutine. pprof.Do and pprof.SetGoroutineLabels replace getg().labels, so reenterMarked becomes false, and a later Close on that goroutine takes closeJoin and waits for loads, which includes itself. A probe that called Close inside pprof.Do from the Loader was still blocked at 400ms. The rebuttal's AfterFunc probe passes because loadCtx starts that callback already marked; it does not cover another cache or a label swap. The skip needs a per-cache, per-goroutine token that user label changes cannot drop and that another cache cannot observe.
minor: admit's recover calls rollback while still holding mu, and rollback ranges resident. A panic from that range (or from linkMRU on the rebuild) re-enters the same deferred recover, which calls rollback again. Runtime map-iteration panics are unrecoverable throws, so the second panic is not contained: mu stays locked, the flight is never published, and loads.Done has not run, so every later Get, Len, and Close deadlocks. The happy-path recover does unlock and publish loadFailed; this is only the failure of the failure path. Rebuild the list before ranging, or recover a second time and unlock without touching the map.
No other blocker or major issue remains. go test -count=1 . and go test -race -count=1 . passed; go vet . was clean. Direct probes matched the spec for hit copies, single-flight, error-not-cached, capacity-1 and empty-key LRU, Len ignoring in-flight loads, orphaned success, discard-on-close, overlapping Close, and a Loader-context context.AfterFunc that calls Close.
