package blockcache // import "blockcache"

Package blockcache provides a bounded, concurrent, single-flight block cache in
front of a slow backing store.

Resident entries are kept in LRU order and bounded by a fixed capacity.
Concurrent misses for the same key share one Loader call. Every Get returns a
fresh copy of the block, so callers may mutate what they receive.

VARIABLES

var ErrClosed = errors.New("blockcache: closed")
    ErrClosed is returned by Get once the cache has been closed.

var ErrSelfGet = errors.New("blockcache: Loader called Get for the key it is loading")
    ErrSelfGet is returned by Get when it is called, with the Loader's ctx (or a
    ctx derived from it), from inside the Loader call that is loading that same
    key. Waiting would deadlock, because the load would wait on itself.


TYPES

type Cache interface {
	// Get returns a COPY of the block for key, loading on a miss. Concurrent Gets
	// for the same absent key cause exactly one Loader call; all receive its result.
	//
	// ctx must be non-nil. A hit is served even if ctx is already Done; a miss
	// with a Done ctx returns ctx.Err() without starting or joining a load.
	Get(ctx context.Context, key string) ([]byte, error)
	// Len is the number of resident entries. Resident-only; it may lag a completion
	// by one critical section and is never above capacity.
	Len() int
	// Close cancels in-flight loads, waits for their Loader calls to return, wakes
	// every waiter with ErrClosed, drops all entries, and returns nil. Idempotent.
	Close() error
}
    Cache is a bounded, concurrent, single-flight block cache.

func New(capacity int, load Loader) Cache
    New returns a Cache holding at most capacity entries. It panics if capacity
    < 1 or load == nil.

type Loader func(ctx context.Context, key string) ([]byte, error)
    Loader fetches the block for key. The cache calls it at most once per
    in-flight miss for a key (single-flight). It is given a cache-scoped
    context, not any single caller's. A Loader MUST return promptly when its ctx
    is Done.

    A Loader may call Len, and Get for other keys. If it calls Get for the
    key it is loading, with its own ctx (or one derived from it), that Get
    returns ErrSelfGet. A Loader must not call Close on its own cache: Close
    waits for every in-flight Loader call to return, so doing so deadlocks.
    A cycle of Loaders across keys (A's Loader gets B, B's Loader gets A) cannot
    be detected; it ends only when the callers' contexts are Done or the cache
    is closed.

type PanicError struct {
	Key   string
	Value any    // the value passed to panic
	Stack []byte // debug.Stack() captured in the recovering goroutine
}
    PanicError is the error waiters receive when the Loader panics. Like any
    Loader error it is not cached. It keeps the panic value and the stack,
    so a programming bug can be told apart from a transient load failure.

func (e *PanicError) Error() string

func (e *PanicError) Unwrap() error
    Unwrap returns the panic value if it is an error, else nil.
