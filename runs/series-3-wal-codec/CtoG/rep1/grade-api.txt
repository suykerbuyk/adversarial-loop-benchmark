package walcodec // import "walcodec"

Package walcodec encodes a sequence of write-ahead-log records to a framed byte
stream and decodes it back.

# Wire format (version 2)

All integers are big-endian.

    stream = version(1) frame*
    frame  = len(4) type(1) payload(len-1) crc(4)

version is 1 or 2; Encode always writes 2. Any other version is rejected
before any frame is read. A version-1 stream may contain only types 1 and 2;
a version-2 stream may contain all three types.

len is a uint32 counting type+payload only; the trailing crc lies outside len.
crc is the CRC-32 (IEEE) of type+payload. len is capped at 16 MiB (16<<20) for
every frame at every depth; a larger len is rejected before anything sized by it
is read or allocated.

Payloads, where strings and byte slices are written as [uint32 len]bytes:

    Put    (type 1) = [klen uint32][key][vlen uint32][value]
    Delete (type 2) = [klen uint32][key]
    Batch  (type 3) = [n uint32] frame{n}

A Batch's inner frames are full frames, crcs included, and are counted in the
outer len. They must consume the Batch payload exactly; fewer or more frames,
or trailing bytes, are corrupt. An inner frame may not extend past its enclosing
payload.

Depth: the top-level stream is depth 0, and a Batch's sub-stream is one level
deeper than the stream holding the Batch. A sub-stream deeper than 8 is rejected
by Decode, and Encode refuses to produce one.

A nil Value and an empty Value both encode as vlen = 0 and both decode to a
non-nil, length-0 []byte. A decoded Batch has non-nil Records.

Every Decode failure wraps ErrCorrupt; test for it with errors.Is, not ==.
Decode errors name the absolute byte offset of the failing frame and the depth
of the stream that holds it. Encode errors start with "walcodec: " and do not
wrap ErrCorrupt.

VARIABLES

var ErrCorrupt = errors.New("walcodec: corrupt stream")
    ErrCorrupt is wrapped by every error Decode returns. Use errors.Is to test
    for it; the returned errors carry additional detail and are not == to it.


FUNCTIONS

func Encode(recs []Record) ([]byte, error)
    Encode writes recs as a version-2 stream, frames in slice order. An empty
    recs yields the one-byte, version-only stream.

    Encode fails, returning a nil slice, if any element (at any depth) is not a
    Put, *Put, Delete, *Delete, Batch or *Batch (including nil elements and nil
    pointers), if Batches nest deeper than 8, or if any frame would exceed the
    16 MiB cap. These errors start with "walcodec: " and do not wrap ErrCorrupt.


TYPES

type Batch struct{ Records []Record }
    Batch groups records into one frame whose payload is a nested framed
    sub-stream. Records may hold Put, Delete and further Batch values, nested at
    most 8 deep.

func (Batch) Kind() uint8
    Kind returns 3, the wire tag for Batch.

type Delete struct{ Key string }
    Delete records that Key was removed.

func (Delete) Kind() uint8
    Kind returns 2, the wire tag for Delete.

type Put struct {
	Key   string
	Value []byte
}
    Put records that Key was set to Value.

func (Put) Kind() uint8
    Kind returns 1, the wire tag for Put.

type Record interface{ Kind() uint8 }
    Record is a single WAL entry. Kind reports the record's wire tag.

    Kind is informational only: having a Kind of 1, 2 or 3 does not make a
    value encodable. Encode accepts only the concrete types Put, *Put, Delete,
    *Delete, Batch and *Batch (pointers non-nil), and dispatches on concrete
    type, never on Kind.

func Decode(b []byte) ([]Record, error)
    Decode parses a version-1 or version-2 stream and returns its records in
    stream order. Decoded records never alias b; decoded Batches always have a
    non-nil Records slice.

    Every failure (missing or unknown version byte, truncated frame, oversize
    or empty len, crc mismatch, unknown type, malformed payload, a Batch in a
    version-1 stream, a Batch whose frames do not consume its payload exactly,
    nesting deeper than 8) returns a nil slice and an error wrapping ErrCorrupt.
